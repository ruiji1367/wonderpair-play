Use Phone Controllers

Use two phones as controllers. Install Connector once on Windows.

Phone controller setup

  1. Download Connector. It lets your PC run WonderPair without internet. Download for Windows
  2. Install it once. Run WonderPair_Game_Setup.exe and accept Windows Firewall access.
  3. Start local play. Choose Wi-Fi or your PC hotspot when Connector opens. Start Local Play
  4. Pair your phones. Connect both phones to selected network, then scan one QR code per player.

Connector did not open? Install it first, then try Start Local Play again.

What you need

Windows PC · Same Wi-Fi or PC hotspot · Two phones optional
